## Review Focus

1. **V4A 解析的失败闭合**：缺 `*** Begin Patch`/`*** End Patch` 信封、或提取路径数为 0 → `INVALID_PATH_OR_CALL`；`*** End of File` 是标记不是路径；patch 中**每个**路径（Add/Update/Move to/Delete）逐一过写范围+保护检查。
2. **相对路径基准**：提取路径一律经 `targetPath(path, call.cwd)`（会话 cwd）；无 cwd → `CWD_REQUIRED` 拒绝。
3. **按参数区分 effect 默认方向**：未知/缺失/非字符串参数取值一律 `write`；`readWhen` 显式名单。
4. **纵向流程证据真实性**：Task 5 只记录真实发生的阶段与命令输出；宿主=ZCode（本会话）；guard 层宿主验证单列未完成。
5. **环境变量覆盖可见**：`GSTACK861_TEST_COMMIT` 生效时必须 stderr 打印显式警告；就绪脚本密钥缺失时 exit 2 并说明，不得静默跳过。
